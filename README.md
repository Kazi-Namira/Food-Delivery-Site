# Food-Delivery-Site

A responsive food delivery website built with HTML, CSS, and JavaScript.

## Live Site
Check out the live version here:  
[https://onlinefood-delivery-site.vercel.app/](https://onlinefood-delivery-site.vercel.app/)

## Features
- Responsive design for different screen sizes  
- Product cards with "Add To Cart" buttons  
- Toggle to show more or fewer products  
- Testimonials section  
- Newsletter subscription form  

## Technologies Used
- HTML5  
- CSS3  
- JavaScript (Vanilla)  

## How to Run Locally
1. Clone the repository:  
   `git clone https://github.com/Kazi-Namira/Food-Delivery-Site.git`  
2. Open `index.html` in your web browser.
